# کیت تدوین کلام

محیط مشترک تدوین فارسی با Codex در VS Code؛ مستقل از Aitudio و استودیو. همکار فایل و هدف را می‌دهد، Codex ابزار محلی را اجرا می‌کند و پروژهٔ قابل‌ادامه و MP4 تحویل می‌دهد. اشتراک یا دسترسی Codex جداگانه لازم است؛ این ریپو مدل یا اعتبار API ارائه نمی‌کند.

## شروع برای همکار

۱. ریپوی خصوصی را روی درایو D یا یک درایو غیر C کلون و همان پوشه را در VS Code باز کن. Git، Node.js نسخهٔ ۲۲٫۱۲ به بالا، Chrome یا Edge و افزونهٔ Codex از قبل نصب باشند. ابزار نصب‌شدهٔ موجود روی C قابل استفاده است؛ مسیرهای نصب و کش کیت روی درایو ریپو تنظیم می‌شوند.

۲. در Codex بنویس:

> AGENTS.md را بخوان و ابزارهای این کیت را روی همین درایو آماده کن. بعد برای [نام رسانه یا مشتری] با فایل‌های [مسیرها] یک تدوین جذاب بساز. سوال‌های ضروری را بپرس و تنظیمات باقی‌مانده را از محتوا انتخاب کن.

Codex می‌تواند این دستور را اجرا کند:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/setup.ps1
```

برای Remotion اختیاری:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/setup.ps1 -WithRemotion
```

نصب اولیه به اینترنت نیاز دارد؛ رندر با دارایی‌های بسته‌بندی‌شده محلی است. پیش از اجرای دوبارهٔ setup پیش‌نمایش‌ها و رندرهای همین کیت را ببند تا فایل ابزار در ویندوز قفل نباشد. برای Edge مسیر فایل اجرایی را در `KALAM_BROWSER_PATH` بده. نصب ابزار، آماده‌سازی فونت و تست رندر با ساخت ویدیو یکی نیست؛ `docs/verification.md` شواهد واقعی را ثبت می‌کند.

## یک سفارش واقعی

> برای کلام تازه چناران از این خبر موشن بساز. خبر: … اگر سناریو لازم دارد، اول بپرس متن خبر را بازنویسی کنی یا عیناً بماند. متن نریشن را برای تأیید بده، بعد منتظر فایل صوتی من بمان. خروجی عمودی باشد.

> برای مشتری یک فروشگاه، روی اجرای این بلاگر تدوین تبلیغاتی انجام بده. فایل: … هدف و CTA: … رنگ و لوگوی مشتری: … صدای اصلی را نگه دار.

> از این عکس‌ها یک موشن تبلیغاتی بی‌نریشن بساز. متن قطعی: … برند: … بدون تولید صدای انسانی.

پیش‌فرض ۱۰۸۰×۱۹۲۰، ۳۰ فریم است؛ افقی، مربعی و ۴:۵ با درخواست قابل انتخاب‌اند. برای ویدیوی گفتاری، تمام گفتار از نظر روایت و گرافیک پوشش داده می‌شود؛ قرار نیست هر جمله با یک کارت تکراری جایگزین شود.

## صدا و تأیید متن

برای خبر متنی فاقد سناریو، ابتدا انتخاب «عین متن / بازنویسی برای نریشن» پرسیده می‌شود. متن پیشنهادی باید تأیید شود؛ نریشن را کاربر بیرون از کیت تولید و فایلش را ارسال می‌کند. تدوین دارای نریشن تا دریافت آن زمان‌بندی نهایی نمی‌شود. حالت بدون نریشن با انتخاب کاربر ممکن است؛ «بدون صدا» یعنی هیچ موسیقی یا SFX هم اضافه نشود. صدای حاضر در ویدیوی اصلی حفظ می‌شود مگر تغییر خواسته شود. هیچ TTS یا API پولی به‌طور خودکار اجرا نمی‌شود.

## داخل ریپو

- `brands/`: پنج پروفایل برند + پروفایل مستقل مشتری؛ هر برند وضعیت تأیید دارایی‌هایش را دارد.
- `assets/`: لوگو و سربرگ رسمی، فونت‌ها و SFX مشترک مجاز برای تیم.
- `library/fonts.html`: نمایش و مقایسهٔ فونت‌ها با متن دلخواه؛ کاربردهای پیشنهادی در `docs/fonts.fa.md`.
- `.agents/skills/`: مهارت تدوین کلام و راهنماهای موتور؛ پس از کلون، گفت‌وگوی تازهٔ Codex باز کن.
- `library/`: دستورهای طراحی قابل جست‌وجو، با ابزار، تکنیک، مسیر نمونه و کاربرد؛ قالب اجباری نیستند.
- `examples/`: نمونه‌های کوچک قابل اجرا برای هر دو موتور؛ خبر یا مشتری واقعی نیستند.
- `.local/projects/`: فیلم، نریشن، متن، پروژه و خروجی سفارش‌ها؛ در Git ثبت نمی‌شوند.
- `docs/`: شروع کار، سناریو، طراحی، صدا، کنترل کیفیت، مجوزها و حافظهٔ ترجیحات.

برای متن و افکت پشت شخصیت و تغییر قاب، [راهنمای ویدیوی چهره‌دار](docs/workflows/presenter.md) را بخوان. [مرجع‌های تصویری مالک](docs/references/instagram-2026-11-02.md) شامل تحلیل نمونه‌ها و سایت‌های ایده است؛ فایل‌های شخصی نمونه در Git نیستند. هر سفارش `sound-plan.json` دارد تا طراحی و اجرای SFX به رویدادهای واقعی متصل بماند. wrapper ابزار حتی کش مبتنی بر home هایپرفریمز را داخل `.cache/tool-home` همین درایو نگه می‌دارد؛ از اجرای مستقیم CLI خارج wrapper پرهیز کن.

## دستورهای کاربردی

```powershell
npm run doctor
npm run new -- --brand chenaran --mode presenter --id my-reel
npm run new -- --brand client --mode motion --engine remotion --id customer-ad
npm run catalog -- --query نمودار
npm run hf -- check .local/projects/my-reel --json
npm run hf -- preview .local/projects/my-reel
npm run hf -- render .local/projects/my-reel --output .local/projects/my-reel/renders/final.mp4 --workers 1
npm run media -- probe D:/path/to/input.mp4
npm test
npm run validate
```

نصب Remotion به معنی رایگان‌بودن استفادهٔ تیمی نیست؛ شرایط فعلی در [راهنمای موتورها](docs/engines.md) آمده است. فیلم خصوصی و خروجی مشتری را برای همکاری در Git نفرست؛ فایل را از مسیر خصوصی مورد توافق تیم منتقل کن.
