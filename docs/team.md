# ادامهٔ کار و همکاری

مالک می‌تواند همکار را با دسترسی لازم به ریپوی خصوصی دعوت کند. کلید API، اشتراک Codex و فایل سفارش همکار از این راه منتقل نمی‌شود. هر همکار پس از clone پوشه را در VS Code باز و گفت‌وگوی تازه ایجاد کند تا مهارت‌های پروژه کشف شوند.

برای ادامهٔ سفارش، پوشهٔ کامل `.local/projects/<id>` از مسیر خصوصی مورد توافق منتقل شود؛ `assets`، متن تأییدشده، timecode، source، `project.json` و گزارش کنار هم باشند. فرمان «ادامه بده» باید از همین فایل‌ها وضعیت را بازیابی کند، نه از حدس یا حافظهٔ گفت‌وگوی قبلی.

تغییر ابزار، قواعد مشترک، برند و کتابخانه با branch و review وارد main شود. تغییر سلیقهٔ یک مشتری فقط در پروژهٔ خودش باقی بماند مگر مالک تعمیم را تأیید کند. `AGENTS.md` مشترک کوتاه بماند و جزئیات موتور در مهارت مربوطه باشند.
