# بازبینی قبل از تحویل

`REVIEW.md` هر سفارش مدرک همان سفارش است. خانهٔ چک بدون بررسی واقعی تیک نخورد.

| محور | شاهد مورد انتظار |
| --- | --- |
| محتوا | متن و اعداد مطابق منبع؛ انتساب درست؛ CTA تأییدشده |
| برند | تصویر سربرگ اصلی، نسبت و خوانایی؛ فوتر و @ در جهت درست |
| فونت | فایل واقعی و وزن موجود؛ فارسی سالم؛ زیرنویس متمایز |
| طراحی | هر بیت تصمیم تصویری؛ تنوع معنادار؛ صورت و سوژه آزاد |
| زمان | caption از صدای واقعی؛ مرز صحنه و ورود/خروج بدون flash |
| صوت | گفتار واضح؛ SFX همگام؛ peak/loudness ثبت و بازبینی شنیداری صادقانه |
| فنی | check موتور، قاب‌های آغاز/میانه/انتها و انتقال‌ها، رندر کامل و ffprobe |
| تحویل | MP4 قابل پخش، وضوح/FPS/مدت واقعی، پروژهٔ منبع و محدودیت‌ها |

قاب‌ها را در اندازهٔ گوشی هم ببین؛ این کار شبیه‌سازی است و به معنی تست روی گوشی واقعی نیست. check مکانیکی جای بازبینی زیبایی‌شناسی را نمی‌گیرد. برای هر ایراد جدی مسیر فریم یا timecode بگذار، اصلاح کن و فقط بخش مرتبط را دوباره بررسی کن.
