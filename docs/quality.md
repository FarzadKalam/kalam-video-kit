# بازبینی قبل از تحویل

`REVIEW.md` هر سفارش مدرک همان سفارش است. خانهٔ چک بدون بررسی واقعی تیک نخورد.

در سه رسانهٔ کلام تازه، پروفایل دایره‌ای و نام فارسی کنار آن و آیدی با جهت LTR در تمام قاب‌ها بررسی شوند. برای سبک تازه، حرکت شبکه/گرادینت، شفافیت کارت‌ها، تنوع غیرکارتی، تغییر اندازه/وزن متن و ورود/خروج مدرن را در قاب‌های واقعی بسنج. حرکت متن نباید فرصت خواندن را بگیرد. visual-plan و منبع/مجوز/تأیید تصویر مولد هم بازبینی شوند.

| محور | شاهد مورد انتظار |
| --- | --- |
| محتوا | متن و اعداد مطابق منبع؛ انتساب درست؛ CTA تأییدشده |
| برند | پروفایل رسمی در نشان دایره‌ایِ کوچک و مدرن؛ فضای آزاد بالای قاب؛ فوتر و @ در جهت درست |
| فونت | فایل واقعی و وزن موجود؛ فارسی سالم؛ زیرنویس متمایز؛ تأکید وزنی/رنگی لازم، شیشه یا glow هم‌رنگ، خوانایی و شیب کنترل‌شده |
| طراحی | هر بیت تصمیم تصویری؛ تنوع معنادار؛ صورت و سوژه آزاد |
| زمان | caption از صدای واقعی؛ مرز صحنه و ورود/خروج بدون flash |
| صوت | گفتار واضح؛ SFX همگام؛ peak/loudness ثبت و بازبینی شنیداری صادقانه |
| طراحی صدا | sound-plan با رویدادهای واقعی timeline تطبیق دارد؛ شمارنده، نوار و reveal رها نشده‌اند؛ بی‌صدا طبق brief رعایت شده |
| شخصیت | لبهٔ مو/دست و flicker، alpha، همگامی لایه‌ها، نبود شخص دوتایی و crop نامناسب بررسی شده |
| فنی | check موتور، قاب‌های آغاز/میانه/انتها و انتقال‌ها، رندر کامل و ffprobe |
| تحویل | MP4 قابل پخش، وضوح/FPS/مدت واقعی، پروژهٔ منبع و محدودیت‌ها |

قاب‌ها را در اندازهٔ گوشی هم ببین؛ این کار شبیه‌سازی است و به معنی تست روی گوشی واقعی نیست. check مکانیکی جای بازبینی زیبایی‌شناسی را نمی‌گیرد. برای هر ایراد جدی مسیر فریم یا timecode بگذار، اصلاح کن و فقط بخش مرتبط را دوباره بررسی کن.
