# وضعیت هویت و فایل‌های تکمیلی

هویت پایهٔ پنج برند آماده است؛ اطلاعاتی که مالک داده دوباره درخواست نشود:

| برند | هویت موجود |
| --- | --- |
| کلام تازه .ir | سربرگ شفاف، overlay، عکس پروفایل رسمی، قرمز، پیدا؛ @kalametaze.ir |
| کلام تازه گلبهار | سربرگ شفاف، overlay، عکس پروفایل رسمی، آبی، پیدا؛ @golbahar.kalametaze |
| کلام تازه چناران | سربرگ شفاف، overlay، عکس پروفایل رسمی، سبز، پیدا؛ @chenaran.kalametaze |
| کلام شهر | لوگو و بنفش سایت رسمی، دوران پرو؛ @kalameshahr |
| تازه سیستم | لوگوی عمومی Kalamapp، تم سرخابی، پیدا؛ https://tazesystem.ir |

دوران پرو با نسخهٔ معمولی و FaNum و محور وزن واقعی اضافه شده است. آریا، پینار، مانلی، پارسا، ایران‌یکان و مربع موجودند. میم به درخواست مالک استفاده نشود؛ فایل درست جایگزین فقط در صورت درخواست تازهٔ مالک بررسی شود.

برای هر سفارش فقط CTA، لینک مقصد و اطلاعاتی که در brief همان سفارش معلوم نیست پرسیده شود؛ آیدی شبکهٔ اجتماعی تازه سیستم حدس زده نشود. فایل برداری لوگوی کلام شهر، موسیقی مجاز و SFX اختصاصی تکمیلی اختیاری‌اند و مانع شروع نیستند. مشتری تبلیغاتی هویت مستقل خودش را در brief می‌دهد.
