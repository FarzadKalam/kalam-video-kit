# اقلام موردنیاز؛ یک‌جا از مالک دریافت شود

کار ابزار و راهنما به این اقلام وابسته نیست. برای تحویل نهایی هویت همهٔ برندها، این بسته را یک‌جا دریافت و سپس پروفایل‌ها را به‌روز کن:

| مورد | موجود | لازم |
| --- | --- | --- |
| کلام تازه .ir | سربرگ و overlay رسمی، رنگ قرمز | آیدی نهایی صفحه، آدرس سایت/CTA قطعی |
| کلام تازه گلبهار | سربرگ، overlay، رنگ و آیدی قبلی | تأیید اینکه @golbahar_kalametaze همچنان صحیح است |
| کلام تازه چناران | سربرگ، overlay، رنگ و آیدی قبلی | تأیید اینکه @chenaran.kalametaze همچنان صحیح است |
| آژانس کلام شهر | لوگوی سایت، رنگ #361775 و آیدی @kalameshahr از سایت رسمی دریافت شد | فقط تأیید نهایی هویت و CTA؛ فایل برداری لوگو در صورت وجود اختیاری است |
| تازه سیستم | لوگوی عمومی Kalamapp و تم سرخابی پیش‌فرض | انتخاب فونت اصلی، تأیید نسخهٔ لوگو/رنگ، آیدی و آدرس معرفی یا CTA |
| پیدا و وزیرمتن | فایل واقعی با وزن‌های موجود | موردی لازم نیست؛ مجوز توزیع خصوصی تیم را مالک تأیید کرده |
| آریا، پینار، مانلی، پارسا، ایران‌یکان ایکس و مربع | از بسته‌های ارسالی اضافه شدند؛ وزن و محور واقعی ثبت شده | موردی لازم نیست |
| میم | به درخواست مالک به علت ایراد بصری غیرفعال شد | فعلاً استفاده نشود؛ فقط اگر مالک بعداً فایل جایگزین معتبر داد دوباره بررسی شود |
| دوران | W_doran ویندوز موردنظر مالک نیست و اضافه نشده | فایل دوران درست با وزن‌ها |

نمونه‌سبک‌های محبوب، فایل موسیقی مجاز یا SFX اختصاصی اختیاری‌اند. برای هر مشتری، نام، لوگو، رنگ و CTA در brief همان سفارش گرفته می‌شود؛ لازم نیست همهٔ مشتری‌ها از قبل در کیت ثبت شوند.
