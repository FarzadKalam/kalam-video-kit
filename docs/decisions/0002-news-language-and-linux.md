# ۰۰۰۲ — هویت خبری تازه و قابلیت حمل ابزار

تاریخ: ۲۰۲۶-۱۱-۰۲؛ وضعیت: پذیرفته‌شده با درخواست صریح مالک.

هویت سه رسانهٔ خبری به پروفایل دایره‌ای همراه نام فارسی کنار آن و آیدی همیشه‌خوانا تغییر می‌کند. دارایی‌های سربرگ قدیمی آرشیوی‌اند، نه پیش‌فرض تولید. جهت خلاق شامل شبکه/گرادینت پویا، شیشه، تایپوگرافی با اندازه و وزن متنوع و شیب سنجیده، ترنزیشن عبارت‌ها، SVG، نمودار مستند و SFX همگام است؛ تعداد یا چینش ثابتی به مدل تحمیل نمی‌شود. زیرنویس می‌تواند تأکید وزنی/رنگی و شیشه یا glow هم‌رنگ بگیرد. سیاست‌ها در پروفایل و راهنمای مشترک‌اند تا ادامهٔ کار به حافظهٔ چت وابسته نباشد.

برنامهٔ نیازهای تصویری پیش از جست‌وجو/دریافت/تولید ثبت می‌شود. ابزار تصویرساز Codex در صورت دسترسی قابل استفاده است؛ تولید به تأیید کاربر برای همان نیازها وابسته است و fallback پولی مخفی ندارد. رندر فقط دارایی محلی سفارش را مصرف می‌کند.

برای Windows و Linux x64/glibc، FFprobe از loader رسمی چندسکویی با نسخهٔ pinشده می‌آید؛ FFmpeg قبلاً چندسکویی بود. کش و home ابزارها در wrapperها محدود به checkout، مرورگر از سیستم موجود، و لینک Remotion بسته به سیستم directory symlink یا Windows junction است. Linux setup مستقل و CI دو سکویی دارد. هزینهٔ نگه‌داری دو مسیر نصب پذیرفته می‌شود تا نصب PowerShell پیش‌نیاز لینوکس نباشد. نبود میزبان لینوکس این جلسه به‌صراحت در شواهد ثبت می‌شود؛ CI تعریف‌شده به معنی passed نیست.
