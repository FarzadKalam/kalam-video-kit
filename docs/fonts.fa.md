# انتخاب فونت و نقش‌های پیشنهادی

انتخاب فونت از `assets/fonts/catalog.json` و نمونهٔ قابل‌مشاهدهٔ `library/fonts.html` است. سیاست تأییدشدهٔ مالک: رسانه‌های کلام تازه و تازه سیستم با پیدا؛ کلام شهر با دوران پرو که اکنون بسته‌بندی شده است. میم به علت ایراد بصری به درخواست مالک غیرفعال و از فایل‌های مشترک خارج شد. سایر خانواده‌ها بیشتر برای تبلیغات و مشتریان‌اند. کاربردهای جدول راهنمای شروع‌اند؛ انتخاب صریح کاربر مقدم است.

| خانواده | پیشنهاد کاربرد | نکتهٔ عملی |
| --- | --- | --- |
| پیدا | خبر، تبلیغ، تیتر، متن و زیرنویس | فایل واقعی ۴۰۰،۶۰۰،۷۰۰،۹۰۰؛ وزن ناموجود جعل نشود |
| وزیرمتن | زیرنویس، متن طولانی، رابط و عدد | متغیر ۱۰۰–۹۰۰؛ برای تفاوت زیرنویس با تیتر انتخاب خوبی است |
| آریا | تیتر، موشن‌تایپوگرافی، متن و هویت تبلیغاتی | فایل متغیر؛ نسخهٔ FaNum برای ارقام فارسی. Normal/Heavy/UltraBold alias جدا دارند |
| میم | استفاده نشود | به درخواست مالک غیرفعال؛ فایل‌ها و CSS مشترک آن حذف شدند؛ آرشیو اصلی فقط در incoming محلی باقی است |
| پینار | موشن تیتر، معرفی و هویت تبلیغاتی، عبارت کوتاه | متغیر با محورهای واقعی wght،KSHD،DSTY؛ مقدار هر محور با فریم نمونه بررسی شود |
| مانلی | عبارت نمایشی کوتاه، امضا و لحن شخصی | تک‌وزن؛ برای زیرنویس پیوسته، اول خوانایی در اندازهٔ گوشی بررسی شود |
| پارسا | عبارت دست‌نویس، تیتر کوتاه و لحن صمیمی | تک‌وزن، نسخهٔ معمولی و FaNum؛ bold مصنوعی نساز |
| ایران‌یکان ایکس | متن تبلیغاتی، رابط، معرفی نرم‌افزار و زیرنویس | متغیر ۱۰۰–۱۰۰۰ با محور dots؛ نسخهٔ معمولی و FaNum |
| مربع | تیتر هندسی، موشن محصول و تبلیغات | متغیر ۲۵۰–۹۰۰ با محور kash؛ UltraLight وزن۲۰۰ جدا و Heavy با alias جدا |
| دوران پرو | هویت و تیتر کلام شهر؛ تبلیغات | فایل متغیر واقعی ۱۰۰–۹۰۰؛ نسخهٔ معمولی و FaNum؛ با W_doran ویندوز متفاوت است |

فایل‌های ارسالی بر اساس جدول نام، وزن OS/2، محور fvar و وجود حروف پ،چ،ژ،گ بررسی شده‌اند. این بررسی به‌تنهایی کیفیت حروف‌چینی را اثبات نمی‌کند؛ فونت‌های منتخب باید در مرورگر و در رندر دیده شوند. برای سبک‌های هم‌وزن، `cssFamily` در catalog مرجع است تا CSS یکی را با دیگری جایگزین نکند.

محور Aria در فایل تا ۱۱۵۰ وجود دارد؛ CSS `font-weight` حداکثر ۱۰۰۰ را می‌پذیرد. در صورت نیاز به مقدار فراتر، از محور واقعی `font-variation-settings: 'wght' 1150` استفاده و تصویرش را بررسی کن. در پینار محور DSTY چند سبک را در یک فایل نگه می‌دارد؛ زمان و مقدار آن باید مانند بقیهٔ موشن‌ها deterministic باشد.

برای کم‌کردن حجم و جلوگیری از نسخه‌های تکراری، ظرف WOFF2 ترجیح داده شده است؛ فایل‌های TTF/OTF منتخب به WOFF2 تبدیل شده‌اند و hash منبع و خروجی ثبت شده است. آرشیو خام، PDF و نمونهٔ شخصی وارد Git نمی‌شوند. فایل فونت در ریپوی خصوصی با اجازهٔ مالک است و عمومی منتشر نمی‌شود.
